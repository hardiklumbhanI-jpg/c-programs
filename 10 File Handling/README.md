# File Handling in C

This folder contains C programs that demonstrate **File Handling** concepts such as creating, reading, writing, appending, copying, renaming, deleting, and working with binary files.

---

## 📂 Programs Included

| No. | Program Name | Description |
|-----|--------------|-------------|
| 01 | Create File | Create a new file |
| 02 | Write File | Write text into a file |
| 03 | Read File | Read data from a file |
| 04 | Append File | Append data to an existing file |
| 05 | Copy File | Copy contents of one file to another |
| 06 | Count Characters | Count characters in a file |
| 07 | Count Words | Count words in a file |
| 08 | Count Lines | Count lines in a file |
| 09 | Student Record | Store student records in a file |
| 10 | Employee Record | Store employee records in a file |
| 11 | Binary File Write | Write data to a binary file |
| 12 | Binary File Read | Read data from a binary file |
| 13 | Rename File | Rename an existing file |
| 14 | Delete File | Delete a file |
| 15 | Binary File Copy | Copy one binary file to another |

---
