# Structures in C

This folder contains C programs that demonstrate the use of **Structures**, **Unions**, **Enums**, and **Typedef** in the C programming language. These programs help beginners understand how to store and manage related data efficiently.

---

## 📂 Programs Included

| No. | Program Name | Description |
|-----|--------------|-------------|
| 01 | Structure Basics | Basic structure declaration and usage |
| 02 | Student Structure | Store and display student information |
| 03 | Employee Structure | Store employee details |
| 04 | Array of Structures | Handle multiple records using structures |
| 05 | Nested Structure | Use one structure inside another |
| 06 | Structure to Function | Pass a structure to a function |
| 07 | Function Return Structure | Return a structure from a function |
| 08 | Pointer to Structure | Access structure members using pointers |
| 09 | Structure with Array | Structure containing an array |
| 10 | Structure Sort | Sort structure records by marks |
| 11 | Structure Search | Search a structure record |
| 12 | Union Example | Demonstrate the use of unions |
| 13 | Enum Example | Demonstrate enumeration in C |
| 14 | Typedef Structure | Simplify structure declarations using typedef |
| 15 | Structure File Handling | Store structure data in a file |

---

## 📚 Concepts Covered

- Structure Declaration
- Structure Initialization
- Accessing Structure Members
- Array of Structures
- Nested Structures
- Passing Structures to Functions
- Returning Structures from Functions
- Pointer to Structure (`->` Operator)
- Structure Sorting
- Structure Searching
- Union
- Enumeration (enum)
- Typedef
- File Handling with Structures


## 🎯 Learning Outcomes

After completing these programs, you will be able to:

- Create and use structures in C
- Manage multiple records efficiently
- Use pointers with structures
- Pass structures to functions
- Return structures from functions
- Understand unions and enums
- Use typedef for cleaner code
- Store and retrieve structure data from files
