# Functions in C

This folder contains C programs based on Functions in the C programming language.

## Topics Covered

- Function Declaration
- Function Definition
- Function Call
- Function with Arguments
- Function without Arguments
- Function with Return Value
- Function without Return Value
- Mathematical Programs using Functions

## Programs Included

1. Function without Argument & without Return Value
2. Function with Argument & without Return Value
3. Function without Argument & with Return Value
4. Function with Argument & with Return Value
5. Sum using Function
6. Subtraction using Function
7. Multiplication using Function
8. Division using Function
9. Even or Odd using Function
10. Prime Number using Function
11. Factorial using Function
12. Fibonacci using Function
13. Swap using Function
14. Largest of Two Numbers
15. Largest of Three Numbers
16. Power using Function
17. Reverse Number
18. Palindrome Number
19. Armstrong Number
20. Simple Calculator using Function

## Learning Outcomes

After completing these programs, you will understand:

- Function creation
- Function calling
- Passing arguments
- Returning values
- Code reusability
- Modular programming

## Requirements

- GCC / Turbo C / Code::Blocks / Dev-C++ / VS Code with MinGW
