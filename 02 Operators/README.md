# Operators in C

This folder contains C programs demonstrating different types of operators.

## Programs Included

1. Arithmetic Operators
2. Assignment Operators
3. Relational Operators
4. Logical Operators
5. Increment and Decrement Operators
6. Bitwise Operators
7. Ternary Operator
8. Operator Precedence
9. Even or Odd Number
10. Temperature Converter

## Concepts Covered

- Arithmetic Operations
- Assignment
- Comparison
- Logical Expressions
- Bitwise Operations
- Conditional Expressions
- Operator Priority
